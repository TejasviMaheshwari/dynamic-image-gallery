# Dynamic Image Gallery

A simple image gallery created using **HTML5 and CSS3** as part of a web development assignment. The gallery displays nature-themed images in multiple columns using CSS Flexbox.

## 📌 Project Overview

The Dynamic Image Gallery demonstrates how to arrange images in a structured layout using HTML elements and CSS styling. It features a centered heading and five columns containing images of mountains, oceans, beaches, skies, camping, and night views.

## ✨ Features

* Clean and simple gallery layout
* Five image columns
* Nature-themed image collection
* Flexbox-based alignment and positioning
* Basic HTML and CSS styling
* No external libraries or frameworks required

## 🛠️ Technologies Used

* **HTML5** – Webpage structure
* **CSS3** – Styling, Flexbox layout, and image sizing

## 📂 Project Structure

```text
dynamic-image-gallery/

├── Camp.png

```

## 🚀 How to Run

1. Clone or download this repository.
2. Make sure all image files are in the same directory as `index.html`.
3. Open `index.html` in any modern web browser.
4. Explore the image gallery.
